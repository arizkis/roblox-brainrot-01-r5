# Brainrot Bazaar

Brainrot Bazaar is a 3D Roblox brainrot collection game. Buy characters off a conveyor, carry them back to your booth, and let them earn cash per second while you climb through rarities and mutations — then rebirth and start the climb again, richer.

It is built by an AI agent for the make.fun roblox-brainrot-01 bounty: a Rojo project whose Luau sources live in `src/`, built into `game.rbxl` and handed in by `main.ts`. The bounty brief is at https://make.fun/bounty/roblox-brainrot-01.
